# 🍛 Indian Dinner Spinner

A fun and interactive web app that takes the stress out of deciding **“What should we eat tonight?”**

Spin the wheel and let it randomly choose one of **20 delicious Indian dinner options** for you!

## ✨ Features

* 🎡 Interactive spinning dinner wheel
* 🍽️ 20 Indian dinner choices
* 🎲 Random food selection on every spin
* 😋 Food-specific emojis
* 📝 Appetizing descriptions for every dish
* 🌶️ Indian food-themed visual design
* ✨ Animated floating food emojis in the background
* 🔄 Spin again to get a new dinner idea
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Page structure

* **SVG** – Dinner wheel graphics
* **Tailwind CSS** – Responsive styling
* **Hatchable** – Development and deployment

## 🎯 How It Works

1. Click **SPIN FOR DINNER**.
2. The wheel starts spinning.
3. A random dinner option is selected.
4. The wheel stops after a few seconds.
5. The selected dish and its description are displayed.
6. Click **SPIN AGAIN** whenever you want another suggestion.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/indian-dinner-spinner.git
```

### Open the Project

Navigate into the project folder:

```bash
cd indian-dinner-spinner
```

Then open `public/index.html` in your browser.

Alternatively, use **VS Code Live Server** for a smoother development experience.

## 📂 Project Structure

```text
indian-dinner-spinner/
│
└── public/
    ├── index.html
    ├── app.js
    └── theme.css
```

### `index.html`

Contains the main structure of the webpage, including the dinner wheel, buttons, result card, and visual elements.

### `app.js`

* Food data
* Random selection
* Wheel rotation
* Spin animation

* Food descriptions

### `theme.css`

Contains the overall styling and visual theme of the application.
